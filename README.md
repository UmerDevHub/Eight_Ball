# 🚀 Farhan YT - 8 Ball Pool Store (Setup & User Guide)

Welcome to your premium 8 Ball Pool Store website! This guide is written for **non-technical users** to help you run, host, and update your website in under 5 minutes without writing a single line of code.

---

## 💻 Method 1: Running Locally (Offline)
You do not need to install any software, servers, or programming languages to run this website on your computer.

1. **Download the project folder** to your computer.
2. Double-click the **`index.html`** file.
3. The website will open instantly in your web browser (Chrome, Edge, Safari, Firefox).

## 🌐 Method 2: Hosting the Website Online (FREE)
To make your website accessible to customers on the internet (e.g., `yourname.vercel.app` or `yourdomain.com`):

### Step 1: Upload to GitHub (First-Time Setup)
1. Go to [GitHub.com](https://github.com/) and create a free account.
2. Click **New Repository**, name it (e.g., `8ball-store`), keep it **Public**, and click **Create repository**.
3. Upload all the files from your folder (`index.html`, `script.js`, `styles.css`, and images) into this repository.

### Step 2: Link to Vercel (Hosting)
1. Go to [Vercel.com](https://vercel.com/) and sign up using your GitHub account.
2. Click **Add New** > **Project**.
3. Select your GitHub repository (`8ball-store`) and click **Import**.
4. Click **Deploy**. Your website is now live! Vercel will give you a free link (e.g., `8ball-store.vercel.app`).

---

## ⚡ How to Save & Publish Changes Live
Once the site is hosted, you can publish updates with one click directly from the website:

1. Go to [GitHub Developer Settings Token Page](https://github.com/settings/tokens) and click **Generate new token (classic)**.
2. Check the **`repo`** permission checkbox and click **Generate token**. Copy this token key.
3. Open your live website, enter **Admin Mode** (using the padlock and password `Khan@1122`).
4. Click **Settings** in the bottom admin control bar.
5. Paste your details:
   * **GitHub Username:** (e.g., `UmerDevHub`)
   * **Repository Name:** (e.g., `Eight_Ball`)
   * **Branch:** `main`
   * **GitHub Personal Access Token:** (Paste the token key you copied in Step 2)
6. Click **Save Settings**. (This is saved securely in your browser).
7. Now, whenever you edit prices, click the **🚀 Publish Live** button in the bottom admin bar. The website will automatically update itself on Vercel within 10 seconds!
